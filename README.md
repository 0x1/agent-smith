# Agent Smith

A one-off hackathon exploring repository-aware API maintenance: identify what an application uses, investigate relevant upstream changes, and hand off an alert or a verified repair.

Start with [the project direction and proposed architecture](coordination/PROJECT.md). Agents should then read [AGENTS.md](AGENTS.md), [the coordination protocol](coordination/README.md), and [the unclaimed task board](coordination/BOARD.md). Copy the [task template](coordination/tasks/TEMPLATE.md) to claim work and record checkpoints, decisions and handoffs.

The repository currently contains planning and coordination documents only. The proposed demo and integrations are not implemented. The owner will invite CTO; no agent is activated by these documents.

Hackathon deadline: **October 31, 2026, 4 PM Pacific (PDT; 23:00 UTC)**.
