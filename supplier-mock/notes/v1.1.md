# Supplier API v1.1: inventory response tidy-up

Endpoint: `GET /v1/inventory/{sku}`

- Removed: `warehouse`. Warehouse codes now come from the logistics API.
- Added: `restock_eta`, the expected restock date (`YYYY-MM-DD`), or `null` when none is planned.
- Unchanged: `sku`, `stock`, `updated_at`. `stock` still means units available to sell.
